# 灵犀桥 V0.1 虚构演示工作区

这是可直接用 Obsidian 打开的完整虚构示例，不含真实人物、真实聊天记录或 SQLite 索引。

阅读顺序：

1. `people/`：虚构人物林夏。
2. `events/`：一次虚构的周末散步约定。
3. `attachments/`：按原样保留的虚构材料原文，其中包含一份 24 条、2 位说话人的长聊天，供本地统计、主题片段和原文回链验收。
4. `sources/` 与 `evidence/`：材料元数据、严格字符定位和原子证据。
5. `reports/`：当前报告正文；`reports/snapshots/` 保存同一版本的不可变快照。

应用打开此目录后会在 `.lingxi/index.sqlite3` 生成可删除、可重建的派生索引。
