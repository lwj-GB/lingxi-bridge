# 开发说明

需要 Python 3.11+、Node.js 22+；桌面构建还需要 Rust 和 Xcode 命令行工具。

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
npm ci
npm ci --prefix apps/desktop
npm run dev:desktop
```

开发时可热更新。构建 Apple Silicon 安装包：`npm run build:desktop`。本地语音依赖见 `requirements-local-speech.txt`，模型需另外下载。R 图表需另装 R 与 ggplot2。

验证：`npm test`、`npm run check:desktop`、`python3 scripts/validate_vault.py --vault examples/vault-template`。

只使用虚构测试资料，不提交密钥、录音、聊天、备份或本机路径。模型凭据在自己的设备配置。
