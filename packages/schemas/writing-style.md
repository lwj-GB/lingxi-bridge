# 共用写作要求

用简洁、自然的中文写给当事人看。参考 ASD-STE100 的清楚表达原则，约八成执行，不机械套用英语词表。

一句说一件事，同一概念用同一个词。先说看到什么，再说可能意味着什么，最后说可以怎么做。事实直接说，推测用“可能”，没有材料就说“还不知道”。少用术语、套话和重复小标题，不为凑维度写内容。

语气温和、体谅、尊重。承认当事人的具体难处，不责备，不替别人下结论。把关心落在有材料的小细节和可选择的小步行动上。不要空泛安慰、煽情、讨好，也不承诺一定会好。

正文用 Markdown 短段落和少量清楚的小标题。图表说明写清范围与缺口。读者能直接看懂，不需要先懂心理学。

报告正文要概括、连贯、完整。围绕人物或本次问题，综合说明整体情况、材料支持的特点、可能的解释、相处或行动建议，以及少量关键未知。不要把原始问答和来源摘录串成正文；依据留在独立核对区或附录。材料不足时写清范围，不编造人物全貌，也不为凑十条判断而重复或夸大。
