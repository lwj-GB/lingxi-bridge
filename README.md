# 灵犀桥

配合文鱼使用的桌面资料工作台。把手机记录按天归档到电脑，集中阅读原话、整理人物和事件、查看报告，也可以回到原文核对。

[下载 macOS 版](https://github.com/lwj-GB/lingxi-bridge/releases/latest) · [手机版](https://github.com/lwj-GB/wenyu-android) · [使用说明](docs/使用指南.md) · [问题反馈](https://github.com/lwj-GB/lingxi-bridge/issues)

- 按日期查看手机归档的记录、笔记和待办。
- 管理人物、事件和相关资料，保留报告历史及原句依据。
- 支持 Markdown 阅读、PDF 导出和可选的 AI 辅助整理。

当前为 **0.2.2 预览版**，安装包支持 Apple Silicon Mac。下载 DMG 后把应用拖入“应用程序”。尚未完成 Apple 公证；系统可能提示无法验证开发者。Windows、Intel Mac 和 Linux 暂无已验证安装包。

资料默认保存在本机。手机归档由用户主动发起；外部 AI 服务需自行配置，所选材料会发送给相应服务。只使用自己有权处理的资料，涉及他人录音前取得同意。AI 内容需要核对，不能用于心理诊断、测谎或替代专业判断。
